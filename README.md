# acesolarenergypk
Solar Panel installation islamabad with Ace Solar

## Contribution guide:

1. Clone the repository
```
- git clone https://github.com/aramay/acesolarenergypk.git
- cd acesolarenergypk
```

2. Create the branch using naming convention
For example, for collaborator use  `dev-<github-username>`
```
git checkout -b dev-fali2k25
```

(Or including a feature slug if they work on multiple things, 
`e.g., dev-fali2k25/nav-fix`)

3. Make changes, commit, and push to your repo

```
git add .
git commit -m "Add solar calculator feature"
git push -u origin dev-fali2k25
```

4. Open the Pull Request 

Once pushed, go to [acesolarenergypk](https://github.com/aramay/acesolarenergypk) on GitHub, click Compare & pull request, and target base: 
`main ⬅️ compare: dev-<username>.`
